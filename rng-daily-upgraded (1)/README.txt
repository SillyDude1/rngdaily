RNG//DAILY — standalone website

Open index.html in any modern browser. No server, build step, account, or dependencies are required.

Included:
- Animated number generation with a rolling-number reveal
- Scores out of 1,000,000, with 512 deterministic pattern signals and bonus weighting for lucky digits including 7
- Pattern descriptions for symmetry, repeats, sequences, lucky digits, round numbers, primes, digit roots, balance, and more
- Best score, streak, seven-day history, local save data, and copy-result button
- Explorer with special samples for symmetry, sequences, round numbers, prime numbers, and more
- Hidden dev mode unlocked by seven logo clicks followed by the word “kernel”
- Infinite mode, custom seed loading, simulated history, neon theme toggle, and a playable Snake mini-game
- Number laboratory with live point breakdowns, head-to-head comparison, and four challenge modes
- Achievement collection, keyboard shortcuts (Space to generate, R to reveal), sound toggle, and reduced-motion support
- Reset control for clearing local data
- Unlimited rolls per day with a visible roll log, rather than overwriting the previous result
- Human-recognizable special-number detectors for meme numbers (69420, 42069, 1337, 80085), triple digits, countdowns, and other familiar patterns
- Separate standalone pages: Play, Lab, Archive, Achievements, About, plus a hidden standalone Kernel Console route
- Developer console is deliberately concealed behind a two-part secret sequence: seven logo clicks followed by the word "kernel"
- Coin economy with purchasable background rewards and Infinite Mode for 1,000 coins
- Daily mission rotation with one-time coin bonuses and mission completion state
- Classic, 30-second Blitz, and Guess the Score play modes
- One completed run per game mode per local day, with visible mode completion states
- Shareable result card with native sharing and clipboard fallback
- Archive search, sorting, favorites, average score, best pattern, and pattern-rate stats
- Extra detectors for Fibonacci numbers, powers of two, alternating digits, perfect squares, and binary-friendly numbers
- Sound toggle, reduced-motion support, live status announcements, and touch-friendly controls
- Responsive layout; no server, build step, account, or dependencies required

The visual direction is an original interpretation of the minimal RNGdle concept, not a copy of its code or assets.
